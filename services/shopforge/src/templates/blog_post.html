ShopForge · Follow on OAuth

Our platform is built on a microservices architecture with services in PHP, Node.js, Python, Go, Java, and GraphQL — all accessible through a single Nginx gateway.

Authentication System

We use JWT tokens for API authentication. The login endpoint is at /api/v1/login. For OAuth flows, see our OIDC discovery document.

Internal Services

Several internal services are accessible during the beta period:

  • Python Flask: /py/ssti, /py/console
  • Go service: /go/proxy, /go/diag
  • Java Spring: /java/template, /java/actuator/env
  • GraphQL: /graphql (introspection enabled)
  • Legacy: /legacy/ (Apache 2.2.15, PHP 5.3.3)
  • SPA: /spa/ (source map, admin panel)

Database Schema

Products are stored in MySQL. The product query endpoint is /php/sqli/products.php. User data including SSN and balance is at /api/v1/users/:id.
